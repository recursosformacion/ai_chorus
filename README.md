# Chorus

Chorus es el espacio personal de trabajo musical del usuario, conectado con OSAP.

No es una interfaz alternativa del catálogo OSAP ni una aplicación exclusiva para directores de coro. Su núcleo es una biblioteca musical personal que funciona de forma autónoma; la colaboración se incorpora cuando el usuario participa en grupos o decide compartir su trabajo.

## Principios

- **La persona y su biblioteca son el centro.** Una cuenta, una biblioteca personal y participación en tantos grupos como corresponda.
- **OSAP es el catálogo compartido.** Chorus mantiene referencias a obras y recursos OSAP; no duplica su catálogo ni sustituye sus reglas de identidad.
- **Lo privado sigue siendo privado.** Los borradores, archivos y colecciones personales pertenecen al espacio del usuario.
- **Editar no significa sobrescribir.** Una edición musical produce un borrador o un nuevo Resource; nunca altera silenciosamente el original.
- **Las capacidades nacen de las relaciones.** No hay perfiles rígidos de músico, director o compositor. Las responsabilidades dependen de cada grupo y contexto.
- **La colaboración es opcional.** El producto debe ser útil a una persona que solo quiere ordenar y estudiar su música.

## Primera entrega

La primera versión se centra en:
1. Escritorio personal y biblioteca.
2. Colecciones y repertorios.
3. Recursos privados y borradores.
4. Integración del editor Muse-encore.
5. Búsqueda e incorporación de Resources de OSAP.

Los grupos, contactos, distribución y agenda se desarrollarán después, sobre una base personal ya útil.
